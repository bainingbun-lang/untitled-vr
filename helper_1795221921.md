# Helper Report - AI2 Steering: Perception and Reaction to Aggression

## Summary
Implemented "PERCEPCION Y REACCION A LA AGRESION" for NPCs across three core files as specified in brief C8_AI2_steering.md.

## Files Modified

### 1. core/npc/npc_perception.gd
- **Vision cone**: Updated `DEFAULT_VISION_HALF_ANGLE_DEG` from 45° to 55° (110° total cone)
- **Vision range**: Updated `DEFAULT_VISION_RANGE` from 12m to 25m
- **Hearing range**: Updated `DEFAULT_HEARING_RANGE` from 8m to 25m
- **Gunshot hearing**: Added `can_hear_gunshot()` function detecting gunshots up to 50m with channel "gunshot"/"disparo"
- **Stimulus evaluation**: Added gunshot channel handling in `evaluate_stimulus()` with 2x priority multiplier

### 2. core/npc/npc_combat.gd
- **Aggression detection methods**:
  - `note_gunshot_impact()` - Direct shot hit (severity 1.0, under_attack=2.0)
  - `note_gunshot_nearby()` - Shot within 3m (severity 0.8, under_attack=1.5)
  - `note_melee_attack()` - Melee/knife attack (severity configurable, under_attack=2.0)
  - `note_aimed_at()` - Aiming loaded weapon <8m for 2s (tracks timer per source, severity 0.6)
- All methods emit events to memory and call behavior's `note_aggression()`

### 3. core/npc/npc_behavior.gd
- **Behavior modes**: "pacifico" (default) and "hostil"
- **Aggression cooldown**: 30s default (`_calm_after_seconds`), decrements in `_apply_behavior_mode()`
- **Reaction logic**:
  - Hostiles (aggressiveness > 0.6): `force_attack`/`force_chase` when in hostil mode
  - Civilians (aggressiveness <= 0.4): `force_flee` when danger or aggression cooldown active
  - Witnesses (sociability > 0.5, aggressiveness <= 0.6): `force_witness_alert`
- **New actions registered**: `hostile_attack`, `civilian_flee`, `peaceful_patrol`, `peaceful_idle`
- **Blackboard exposure**: `_update_blackboard()` writes danger, fear, aggression_cooldown, behavior_mode, visible, target_position, under_attack, alert_level
- **API methods**: `get_behavior_mode()`, `set_behavior_mode()`, `update_aggression_cooldown()`, `note_aggression()`
