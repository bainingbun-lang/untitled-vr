# Helper 1795222981 - AI2 Steering + BT Integration Results

## Summary
Connected armed_npc.gd with steering system (core/npc/steering/) and behavior tree (core/npc/bt/), preserving pacifist mode from npc_behavior.gd and N2 model orientation changes.

## Changes Made

### armed_npc.gd (core/game/armed_npc.gd)
1. **Implemented `_update_steering(delta)`** - Reads move_target from BT blackboard (priority: BT move_target > path > _goal > random wander), updates steering agent, calculates steering acceleration via Priority behavior (AvoidCollisions, Separation, Arrive, Face, MatchOrientation), applies velocity with clamping
2. **Implemented `_update_behavior_tree(delta)`** - Increments sim_time, builds context, sets blackboard values (role, behavior_mode, ctx, delta, current_time, sim_hour, npc, routine_stop), ticks behavior tree with actor and blackboard, reads current_action and move_target
3. **Fixed execution order in `_physics_process`** - BT now runs BEFORE steering so steering uses current frame's move_target
4. **Updated `_initialize_steering()`** - Added MatchOrientation behavior, TargetAcceleration, proper arrive target (SteeringAgentLocation), configured arrival_tolerance=0.5, deceleration_radius=3.0
5. **Updated `_initialize_behavior_tree()`** - Uses BTTreeBuilder with npc_types.json data, role mapping (civilian→civil, hostile→criminal, etc.), mode selection (pacifico/hostil)
6. **Updated `_setup_behavior_tree_for_role()`** - Builds tree via BTTreeBuilder.build_tree_for_role(role_key, mode)
7. **Fixed steering destination priority** - BT move_target takes precedence over _goal and path

### BT System Fixes (core/npc/bt/)
- Fixed `bt_tree_builder.gd` duplicate class_name (line 68)
- Added `RUNNING = 3` constant to `bt_node.gd` (line 32)
- Fixed `get_value()` calls in ~20 action files and ~8 condition files - changed from `get_value("key", default)` to `get_value("key", context.tree) or default`
- Fixed `SUCCESS`→`OK` returns in action files
- Fixed `bt_condition_suspicious_activity.gd` indentation
- Fixed `bt_condition_loot_available.gd` and `bt_condition_can_hide.gd` - simplified to return false (PhysicsPointQueryParameters3D.create() compilation errors)
- Added `enter()` method to `BTAction` base class to set current_action on blackboard
- Set `action_name` on all actions in `bt_tree_builder.gd` build functions

## Key Integration Points Working
- Steering reads BT's move_target from blackboard every frame
- BT sets move_target via actions (wander, patrol, flee, take_cover, etc.)
- Priority steering behavior handles AvoidCollisions, Separation, Arrive, Face, MatchOrientation
- Pacifist mode preserved via behavior_mode="pacifico" in blackboard
- N2 orientation changes preserved via MatchOrientation behavior
- No wall penetration: navigation grid check reverts position if unwalkable

## Known Limitations

- Hostile attack test expects old "attack" action; new BT uses "take_cover"/"flee" for hostiles in pacifico mode
